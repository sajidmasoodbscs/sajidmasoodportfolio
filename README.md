# Welcome to Sajid Masood Portfolio

## Project Info

This is my personal portfolio project showcasing my work, skills, and projects.  
It is built with modern web technologies to ensure performance, responsiveness, and a great user experience.

## How to Run This Project Locally

Make sure you have **Node.js** and **npm** installed.  
Follow these steps to get started:

```sh
# Step 1: Clone the repository
git clone <YOUR_GIT_URL>

# Step 2: Navigate to the project directory
cd sajidmasoodportfolio

# Step 3: Install the dependencies
npm install

# Step 4: Start the development server
npm run dev
